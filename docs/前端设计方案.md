## 1. 前端技术选型

### 1.1 整体架构

| 应用 | 技术栈 | 负责小组 | 说明 |
|------|--------|---------|------|
| **学生端** | Vue 3 + Vite + Element Plus | 学生组 | **推荐Web版**，便于快速开发；也可选择微信小程序（+5%） |
| **管理端** | Vue 3 + Vite + Element Plus | 管理员组 | Web端，必须实现 |
| **AI聊天组件** | Vue 3 组件 | AI组 | 嵌入学生端，可独立开发 |

### 1.2 技术栈详情

#### 核心框架
- **Vue 3**：Composition API + `<script setup>` 语法
- **Vite**：构建工具，快速开发
- **Vue Router**：路由管理
- **Pinia**：状态管理（替代Vuex）
- **Axios**：HTTP请求库

#### UI组件库
- **Element Plus**：PC端UI组件库
  - 学生端：侧重移动端适配（响应式布局）
  - 管理端：侧重桌面端大屏展示

#### 其他依赖
- **dayjs**：日期时间处理
- **mitt**：事件总线（跨组件通信）
- **nprogress**：页面加载进度条
- **@vueuse/core**：Vue组合式工具库

## 5. AI聊天组件设计（独立开发）

### 5.1 组件结构

```
ai-chat/
├── AiChatWidget.vue       # 入口：悬浮按钮 + 聊天面板（学生组引用）
├── AiChatPanel.vue        # 聊天主面板
├── MessageBubble.vue      # 消息气泡（区分用户/AI）
├── QuickActions.vue       # 快捷问题按钮
└── RecommendationCard.vue # AI回复中的座位推荐卡片
```

### 5.2 功能流程

1. 用户点击悬浮按钮 → 展开聊天面板
2. 用户输入问题（或点击快捷问题）→ 发送请求
3. 调用 `/ai/chat` 接口 → 接收响应
4. 根据 `action` 类型渲染不同内容：
   - `text`：纯文本气泡
   - `search_seats`：文本 + 推荐座位卡片
   - `show_reservations`：文本 + 预约列表
   - `redirect`：文本 + 跳转按钮
5. 支持多轮对话（通过 `session_id` 维护上下文）

## 6. 与后端API对接设计

### 6.1 Axios实例配置

```javascript
// src/api/index.js
import axios from 'axios'
import { getToken, removeToken } from '@/utils/auth'
import { ElMessage } from 'element-plus'
import router from '@/router'

const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,  // '/api/v1'
  timeout: 10000
})

// 请求拦截器：添加Token
request.interceptors.request.use(
  (config) => {
    const token = getToken()
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)

// 响应拦截器：统一处理响应
request.interceptors.response.use(
  (response) => {
    const { code, message, data } = response.data
    if (code === 200) {
      return data
    } else {
      ElMessage.error(message || '请求失败')
      return Promise.reject(new Error(message))
    }
  },
  (error) => {
    if (error.response?.status === 401) {
      removeToken()
      router.push('/login')
      ElMessage.error('登录已过期，请重新登录')
    } else {
      ElMessage.error(error.message || '网络错误')
    }
    return Promise.reject(error)
  }
)

export default request
```

## 8. 响应式设计（学生端）

### 8.1 断点设置

```scss
$breakpoints: (

### 8.2 移动端适配要点

- 使用 **Flex/Grid 布局**，避免固定宽度
- 字体大小使用 `rem` 或 `vw` 响应式单位
- 按钮尺寸适合触摸（最小 44px）
- 表单输入框高度适中（40-48px）
- 底部导航栏固定在底部（移动端常用模式）

## 10. 开发规范

### 10.1 代码规范

- 使用 ESLint + Prettier 格式化代码

- `main`：稳定分支
- `feature/student-xxx`：学生端功能分支
- `feature/admin-xxx`：管理端功能分支
- `feature/ai-xxx`：AI组件功能分支

### 10.3 提交规范

```
<type>(<scope>): <subject>

类型：
- feat：新功能
- fix：修复bug
- docs：文档更新
